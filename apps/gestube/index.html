INSTALLATION MANUAL

How to Install GESTUBE on Any Browser & Device

1
Download & Extract the Extension ZIP
Download GESTUBE_Extension_Chrome_Edge.zip and extract it into a folder on your computer (e.g. Downloads/GESTUBE_Extension).
2
Open the Extensions Manager in Your Browser
Type the following address into your browser URL bar and press Enter:
chrome://extensions/
(In Brave use brave://extensions/, in Opera use opera://extensions/)
3
Enable Developer Mode
Toggle the "Developer mode" switch located in the top-right corner of the extensions page.
4
Click "Load Unpacked" & Select Folder
Click the "Load unpacked" button in the top-left toolbar, then select the extracted GESTUBE_Extension folder containing manifest.json.
5
Pin & Enjoy YouTube Ad-Free!
Click the puzzle icon in Chrome to pin GESTUBE. Head to YouTube.com and watch ads disappear automatically!
1
Download & Extract the Extension ZIP
Download GESTUBE_Extension_Chrome_Edge.zip and extract it to a permanent folder.
2
Open Microsoft Edge Extensions
Paste the following URL into Edge's address bar:
edge://extensions/
3
Turn On Developer Mode
In the left sidebar of the Extensions page, switch the "Developer mode" toggle to ON.
4
Click "Load unpacked"
Click the blue "Load unpacked" button and select the extracted folder. GESTUBE is now active!
1
Download the Firefox Package
Download GESTUBE_Extension_Firefox.zip and extract the contents.
2
Open Firefox Debugging Console
Type the following address into Firefox:
about:debugging#/runtime/this-firefox
3
Click "Load Temporary Add-on..."
Click the button and select the manifest.json file inside your extracted Firefox folder. GESTUBE will install immediately with full permissions!
1
Install Kiwi Browser on Android
Kiwi Browser is a Chromium browser for Android that natively supports Chrome extensions. Install it from the Play Store if you don't have it yet.
2
Download the Extension ZIP on Your Phone
Tap Download GESTUBE Extension ZIP to save it directly to your phone's Downloads.
3
Load into Kiwi Extensions
In Kiwi Browser, tap the three dots menu (⋮) -> Extensions. Enable Developer mode, then tap "+ (from .zip / .crx)" and select the downloaded ZIP file!
1
Download the Windows Standalone Package
Download GESTUBE_Windows_v1.0.0.zip (57 MB).
2
Extract the ZIP
Right-click the ZIP and select "Extract All...". Inside you will find GESTUBE.exe.
3
Run GESTUBE.exe
Double-click GESTUBE.exe to launch the standalone desktop YouTube controller! (If Windows Defender SmartScreen displays a warning, click More info -> Run anyway).
1
Download GESTUBE Mobile APK
Download GESTUBE_Mobile.apk (494 KB) directly to your Android device.
2
Allow Unknown Sources / Sideload
When prompted by Android, enable "Allow from this source" in your browser or file manager settings.
3
Tap to Install & Launch
Tap Install. Once completed, tap Open to start enjoying automated YouTube features on mobile!
