🔌 Step 3: Port Forwarding Guide (How Players Connect Through Your IP)
1
Open Router Admin Page: Open your browser and visit http://192.168.1.1 (or http://192.168.0.1) and log in with your router credentials (often on the router sticker).
2
Find Port Forwarding: Navigate to Advanced Settings → Port Forwarding / NAT / Virtual Server → Add New Rule.
3
Enter Port 25565 Settings:
Protocol: TCP (or Both)
Internal Port: 25565
External Port: 25565
Target LAN IP: 192.168.1.xxx (Your PC)
4
Windows Firewall Rule (One-Click Copy): Run Command Prompt as Administrator and paste this to allow Minecraft through Windows Firewall:
netsh advfirewall firewall add rule name="Minecraft 25565" dir=in action=allow protocol=TCP localport=25565
