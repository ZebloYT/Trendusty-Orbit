Quick Setup Guide: How to Get Your GitHub Access Token & 24/7 Hosting

1. Create Repo Go to github.com/new and create a repository (e.g. my-minecraft-server).
2. Generate Token Go to GitHub Tokens (Classic) → Generate new token. Check repo and workflow.
3. Set Permissions In your repo, go to Settings → Actions → General → Workflow permissions and select 'Read and write permissions'.
4. Click Connect & Sync Paste your Repo URL & Token below, then click Connect. EchoNode will push the server and start the 24/7 runner!
